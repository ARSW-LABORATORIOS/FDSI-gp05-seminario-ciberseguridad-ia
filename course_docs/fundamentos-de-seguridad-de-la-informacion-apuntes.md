# Apuntes – Conceptos Clave

Materia: Fundamentos de Seguridad de la Información
Tipo: Apuntes

CIA Triad: Confidencialidad (solo quien debe ver los datos los ve), Integridad (los datos no se alteran sin autorización), Disponibilidad (el sistema funciona cuando se necesita).
Amenaza: evento que puede causar daño. Vulnerabilidad: debilidad que la amenaza explota.
Riesgo = Probabilidad × Impacto.
Criptografía simétrica: misma clave para cifrar y descifrar (AES). Asimétrica: clave pública y privada (RSA).
OWASP Top 10 2021: Broken Access Control, Cryptographic Failures, Injection, Insecure Design, Security Misconfiguration, entre otros.
