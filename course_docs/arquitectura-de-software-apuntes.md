# Apuntes – Patrones Arquitectónicos

Materia: Arquitectura de Software
Tipo: Apuntes

MVC (Model-View-Controller): separa datos, lógica y presentación. Usado en apps web.
Arquitectura Hexagonal (Ports & Adapters): el dominio no depende de frameworks ni BD.
Event-Driven: los componentes se comunican por eventos, útil para microservicios.
Diagrama C4: 4 niveles — Contexto, Contenedor, Componente, Código.
ADR (Architecture Decision Record): documento que registra por qué se tomó una decisión.
