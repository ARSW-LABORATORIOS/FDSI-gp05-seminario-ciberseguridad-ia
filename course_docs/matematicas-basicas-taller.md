# Taller 2 – Derivadas

Materia: Matemáticas Básicas
Tipo: Taller

1. Calcula la derivada de f(x) = 3x⁴ - 2x² + 5.
2. Aplica la regla de la cadena a g(x) = (2x+1)³.
3. Encuentra los puntos críticos de h(x) = x³ - 6x² + 9x.
4. Determina si cada punto crítico es máximo, mínimo o punto de inflexión.
Entrega en clase el próximo miércoles, desarrollo a mano.
