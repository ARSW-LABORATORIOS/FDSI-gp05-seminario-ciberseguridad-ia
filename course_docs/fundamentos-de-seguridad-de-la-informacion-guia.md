# Guía de Laboratorio – Análisis de Riesgos

Materia: Fundamentos de Seguridad de la Información
Tipo: Guía

Objetivo: identificar activos, amenazas y controles en un sistema web.
- Paso 1: Lista los activos (base de datos, servidor, usuarios).
- Paso 2: Para cada activo identifica al menos 2 amenazas.
- Paso 3: Calcula el riesgo (Alto/Medio/Bajo) con la matriz Probabilidad × Impacto.
- Paso 4: Propón un control para cada riesgo Alto.
Entrega individual, máximo 2 páginas.
